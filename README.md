# PCAForge · 主成分分析锻造炉

纯 JavaScript 手写的主成分分析（PCA）教学/演示工具：零框架、零依赖、单文件 `index.html`，在浏览器里实时跑降维与可视化。

## 它做了什么

- **手写线性代数**：数据中心化 → 协方差矩阵 → 雅可比（Jacobi）循环旋转特征分解 → 投影 → 截断重建
- **交叉验证招牌不变量**：幂迭代 + Hotelling 收缩（deflation）逐次求主成分，与雅可比解析特征分解**独立重算**出的主成分方向对齐（|cos| ≥ 0.999）
- **可交互可视化**：数据集一键切换（各向异性高斯团 / 双月牙 / 螺旋 / 瑞士卷 3D→2D），调节样本数 n 与投影维 k，实时看
  - 原始点（蓝）vs 投影重建点（绿）
  - PC1/PC2 方向箭头（红/橙）
  - 方差解释率条形图 + 主成分负载


## 关键数学

- 协方差：`S = (1/(n−1)) · X_cᵀ X_c`，`X_c` 为按列中心化后的数据
- 特征分解：经典循环 Jacobi 旋转，对称矩阵 → 实特征值 + 正交特征向量
- 投影：`X' = X_c · W`（W 为前 k 个特征向量组成的 d×k 负载矩阵）
- 重建：`X̂ = X' · Wᵀ + μ`，截断重建误差 = (1 − 累计解释率)·总方差（等号成立）
- 旋转等变：PCA 在正交变换下协变——旋转数据的投影重建 = 原始数据投影重建再旋转
